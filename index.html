Estrutura e conteúdo

A História do HTML

HTML significa HyperText Markup Language, ou Linguagem de Marcação de Hipertexto. Ele organiza o conteúdo e indica o papel de cada parte: um título, um parágrafo, uma imagem ou um link.

O HTML não é uma linguagem de programação: é uma linguagem de marcação. Sua história começa junto com a criação da World Wide Web e a necessidade de compartilhar documentos ligados entre si.

  1. 1989

    A ideia da Web

    Enquanto trabalhava no CERN, o cientista britânico Tim Berners-Lee propôs um sistema para compartilhar informações entre computadores por meio de documentos conectados por hiperlinks. Essa proposta deu origem à World Wide Web.

  2. 1990–1991

    Nasce o HTML

    Berners-Lee criou as primeiras ferramentas da Web: um navegador, um servidor e o HTML para estruturar documentos. Em 1991, a Web e a descrição inicial do HTML foram apresentadas a outras pessoas. As páginas eram simples, com títulos, texto e links.

  3. 1995

    HTML 2.0

    Com a popularização da Web, tornou-se importante combinar como os navegadores deveriam interpretar as páginas. O HTML 2.0 foi publicado como uma especificação formal, ajudando a estabelecer uma base comum.

  4. 1997–1999

    Mais recursos para páginas

    HTML 3.2 acrescentou recursos que já eram usados na Web. Em seguida, HTML 4.0 e HTML 4.01 fortaleceram a estrutura dos documentos e incentivaram a separação entre conteúdo e apresentação.

  5. 2004–2014

    A evolução do HTML5

    O trabalho no HTML5 ganhou força para acompanhar aplicações e conteúdos mais complexos. A especificação trouxe elementos com significado mais claro, como <header> e <article>, além de suporte integrado a áudio e vídeo. Em 2014, HTML5 tornou-se uma recomendação do W3C.

  6. Hoje

    Uma linguagem em evolução

    O HTML continua sendo atualizado para atender às necessidades da Web. Em vez de depender apenas de grandes versões numeradas, sua especificação é mantida continuamente, com participação da comunidade e dos navegadores.

Estilo e apresentação

A História do CSS

CSS significa Cascading Style Sheets, ou Folhas de Estilo em Cascata. Ele define como o conteúdo HTML aparece: cores, fontes, tamanhos, espaçamentos e a disposição dos elementos na página.

Antes do CSS, era mais difícil manter a aparência consistente entre várias páginas. A proposta do CSS foi separar o conteúdo e sua estrutura visual, facilitando mudanças e deixando os documentos mais organizados.

  1. 1994

    A proposta de Håkon Wium Lie

    O pesquisador norueguês Håkon Wium Lie apresentou a primeira proposta de CSS enquanto trabalhava no CERN. A ideia era permitir que autores definissem a aparência dos documentos sem misturar essas instruções ao conteúdo.

  2. 1996

    CSS1

    O W3C publicou a primeira recomendação oficial do CSS. CSS1 permitia controlar propriedades fundamentais, como fontes, cores, alinhamento de texto e margens. Os navegadores foram, aos poucos, incorporando esse suporte.

  3. 1998

    CSS2 amplia as possibilidades

    CSS2 adicionou recursos para diferentes tipos de mídia, posicionamento e layouts mais elaborados. Com isso, as páginas puderam ter estruturas visuais mais ricas, embora a compatibilidade entre navegadores ainda fosse um desafio.

  4. 2011

    CSS 2.1 consolida a base

    Depois de anos de ajustes para esclarecer comportamentos e melhorar a interoperabilidade, CSS 2.1 tornou-se uma recomendação do W3C e serviu de base para muitas implementações.

  5. CSS moderno

    Uma evolução em módulos

    CSS não avançou como uma única sequência chamada “CSS3”: seus recursos passaram a ser desenvolvidos em módulos separados. Flexbox e Grid facilitaram a criação de layouts; media queries ajudaram a adaptar páginas a diferentes telas; e animações trouxeram movimento sem depender sempre de scripts.

Duas tecnologias, uma mesma web

HTML dá significado e estrutura ao conteúdo; CSS transforma essa estrutura em uma experiência visual. Juntos, eles continuam sendo a base de muitos sites.
